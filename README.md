# Simple Python Chatbot

A lightweight, rule-based text chatbot written in Python. This project demonstrates basic programming concepts such as dictionaries, custom functions, user input handling, and `while` loops.

## Features
* **Instant Responses:** Uses a Python dictionary for fast, rule-based replies.
* **Input Cleaning:** Standardizes user text by handling unexpected casing and trailing spaces.
* **Easy Exit:** Seamlessly closes the session when the user types `quit`.

## How to Run
1. Clone the repository.
2. Run the script using Python:
   ```bash
   python chatbot.py
